How I work

The same four steps, whether it's a PD model or a variance report.

  1. Get the data right

    Reconcile sources, use only what was known at the time, and test for leakage before any model sees the data.

  2. Start simple, then beat it

    Every model is benchmarked against a baseline: rules for fraud, logistic regression for PD, a 60/40 for portfolios.

  3. Check it like a validator

    Backtests, calibration, drift monitoring and stress scenarios, with findings written down, including the ones that hurt.

  4. Write it for the decision

    A memo or dashboard that says what the number means, what it misses, and what to do next.
